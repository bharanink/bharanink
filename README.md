### 👨‍💻 About Me

I am a **Software Engineer & Cybersecurity Researcher** with deep expertise in application security, tool engineering, and full-stack software architecture. My work bridges the gap between **offensive security** (vulnerability assessment, penetration testing, exploit analysis) and **defensive engineering** (DevSecOps, automated code scanning, and deterministic remediation).

- 🛡️ **Cybersecurity & AppSec**: Passionate about vulnerability research, bug bounty hunting, and building automated security assessment and investigation tools.
- 🤖 **Developer Security & AI**: Creator of **[CodeGuard AI](https://github.com/bharanink/CodeGuardAI)** — a privacy-first, on-device security assistant integrating deterministic AST analysis with local generative models.
- ⚡ **Reactive Systems & Libraries**: Author of **[ToastNova](https://github.com/bharanink/toastnova)** — an enterprise-grade React notification library featuring external reactive store architecture and physics-driven gesture interactions.
- 🌐 **Full-Stack & Systems Engineering**: Architecting robust backends, performant microservices, and slick, responsive frontends across modern web and mobile platforms.
- 💡 **Philosophy**: *Secure by design, deterministic by verification, built with precision.*
